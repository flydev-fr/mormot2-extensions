How it works

  1. Register an account -> the server generates a 160-bit TOTP secret
  2. Scan the otpauth:// URL with any TOTP app (RFC 6238)
  3. Login using your username + the current 6-digit code
  4. The server validates the code with +/-30 s window tolerance
